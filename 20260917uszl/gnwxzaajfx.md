# 邯郸妇幼保健院是三甲医院吗？

> 更新时间：2026-09-17 (UTC+8)

我这马上要生孩子了，我跟我老公都有生育险，公司要求必须是三甲医院才给报销，我们这边能生孩子的大医院并不多，我也不知道哪家医院是三级甲等，问哪些朋友，他们都说是在外地生的孩子。我看我们当地很多孕妇都是去的邯郸妇幼保健院生的孩子，有谁知道邯郸妇幼保健院是三甲医院吗？

邯郸市妇幼保健院是集医疗、保健、预防、教学为一体的三级甲公共卫生服务妇幼保健机构，承担全市妇幼保健和基层妇幼保健机构业务指导、监督检查任务，是国家妇幼保健院中医药示范单位。妇女保健部：生殖医学是市政医学的一门重要发展学科，2007年经省卫生厅批准夫精子人工授精技术正式实施，2014年底批准''试管婴儿''技术资格，2015年9月28日''试管婴儿''诞生，2016年9月''无精子症''试管婴儿成功受孕。医院始终坚持“以保健为中心，以生殖健康为宗旨，保健与临床相结合、面向群体、面向基层、预防为主”的工作方针，医院在“四部制”建设的基础上，积极创建重点特色学科，为妇女儿童提供生命周期健康服务。

对于要生孩子的或者治疗不孕不育的，那么都可以在在邯郸妇幼保健院去，医院地址是在邯山区黎明街6号，根据自己的情况可以提前预约挂号，如果是在邯郸妇幼生孩子的话那么需要用到的证件以及物品就有。

- 1. 现金和医保卡(顺产1500—3000元;剖腹产5000—7000元，看具体项目和医院等级)；
- 2. 证件类：医保卡(如果有)结婚证户口本，双方身份证，准生证，围产期检查资料；
- 3. 现金：准备少量现金和卡，有的医院不是所有部门都刷卡的；
- 4. 准备些容易消化的零食：巧克力、饼干等；
在邯郸妇幼医院主要就有妇科、儿科、生殖科、外科、内科、男科等等，不仅是一家国家公立三甲医院，其医疗设备还有各方面的条件也都是非常不错的。
