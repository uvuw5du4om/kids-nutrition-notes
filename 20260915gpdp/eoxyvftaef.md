# 吃了过敏药怀孕怎么办

吃了过敏药怀孕怎么办更新时间:2022-08-23

很多女性在治疗疾病期间，也有可能会出现意外的现象，在这种情况下，很多女性通常都会有吃了过敏药治疗的现象，在吃了过敏药治疗疾病的情况下出现了意外怀孕，这也是很多女性们担心的，害怕在服用西药期间出现意外怀孕是否会给胎儿造成影响，其实我们都知道怀孕的时候是不能吃药的，药物对胎儿的危害是非常大的。那么，吃了过敏药怀孕怎么办?我们一起来了解一下吧。

女性在怀孕初期时，药物对胚胎的影响比较小，在吃西药期间出现了意外怀孕，一般不会对胎儿有太大的影响，毕竟导致畸形的药物种类不多，几率也不算大，所以不必过于担心，一般服用的药物量不是很大，不会有多大的影响。

从优生优育的角度来说，任何的药物对胎儿的生长发育都会产生影响，因此这种情况不排除对胎儿产生发生畸形，等情况，不过每个人对药物的敏感程度不同，部分女性服药后也能生出健康的宝宝。

女性在服用西药期间出现意外怀孕，为了避免出现严重影响。最好是在孕早期，定期的到医院进行相关的孕期检查，如果有其他的异常，及时在医生的指导下对症治疗，以免产生严重影响。

注意事项：其实怀孕是一个非常复杂的过程，怀孕也是一件非常重大的事情，在有疾病的情况下，患者应该要做好避孕的措施，以免在这个时候怀孕，对女性和胎儿都是非常不利的，所以要做好备孕前的准备。
