# 石家庄做三代试管省二院还是省四院好？

> 更新时间：2026-09-11 (UTC+8)

我老婆因患有子宫内膜异位症无法自己怀孕，2018年6月在石家庄通过试管婴儿怀孕，在孕18周时，2018年10月实施胎儿羊水穿刺手术，2018年11月羊水穿刺结果染色体有异常，说是属于X染色体的隐性遗传，无奈选择引产手术。经查明，该缺失基因是由于岳母遗传至我老婆，然后遗传至胎儿的。现想重新怀孕，通过实施第三代试管婴儿技术，对缺陷的基因在胚胎移植前进行胚胎的基因筛查，避免怀上具有基因缺陷的胎儿。现在就在医院的选择上还拿不定主意，想问问大家河北省二院还是四院做三代试管好？ 
查看全部内容

石家庄做三代试管选择省二院比较好，因为省二院是石家庄三代试管婴儿医院之一，而省四院还未开展第三代试管婴儿技术。大家也可以选择石家庄妇产医院，因为现目前石家庄开展了三代试管技术的医院也就只有石家庄妇产医院和省二院这两家。若是选择省二院做三代试管婴儿的话，大家可以先提前了解一下石家庄省二院三代试管流程，这样也可以对接下来要做的事更加了解一些。

虽然河北省四院还未开展第三代试管婴儿技术，但是该医院做第一、二代试管婴儿也比较好。下面还是为大家介绍一下石家庄省二院和省四院做试管的相关情况：

## 1、省二院

河北医科大学第二医院生殖医学科始建于1996年，在河北省率先开展了胚胎植入前遗传学筛查和诊断的临床工作，而且在1997年2月就正式将体外受精-胚胎移植（IVF-ET）技术实施临床，同年3月份即获临床妊娠。下面是省二院生殖科其他信息：

- 1. 开展的医疗项目：第一/二/三代试管婴儿、宫腔内配子移植、胚胎冷冻及冻胚移植、夫精人工授精、辅助孵化、卵子冷冻、卵子赠送、减胎手术、盆腔囊肿穿刺抽吸、男性不育的诊治、附睾睾丸穿刺取精、微量精子冷冻保存、女性内分泌疾病、习惯性流产及免疫性不育的诊治；
- 2. 试管成功率：该医院试管婴儿临床妊娠率在50%以上，其中三代试管成功率可达60%以上；
- 3. 医疗团队：河北省二院崔娜、李立鹏、 郝桂敏等等医生都是该生殖科比较优秀的试管专家；
- 4. 试管费用：该医院一二代试管费用在3-5万元左右，三代试管费用在5-10万元不等。

## 2、省四院

河北医科大学第四医院生殖医学科是该院特色科室，初建于1996年，2001年扩建为生殖医学科，2006年经国家卫生部正式批准开展辅助生殖技术。下面是该医院生殖科的其他信息：

- 1. 开展的医疗项目：常规体外受精-胚胎移植、卵胞浆内单精子注射、囊胚培养、胚胎及囊胚的冷冻和复苏、夫精/供精人工授精、多胎妊娠减胎术、精子冷冻、睾丸穿刺活检、睾丸显微取精等技术以及优生优育遗传咨询、生育力保存等；
- 2. 试管成功率：河北省四院试管婴儿成功率平均在50%左右，已达到国内先进水平；
- 3. 医疗团队：该生殖医学科现有主任医师4名、副主任医师2名，医学博士4名、硕士15名，均为生殖医学专业人员；
- 4. 试管费用：河北省四院因为还未开展三代试管技术，所以该医院总体试管费用不贵，与省二院差不多在3-5万左右。
其实做第一、二代试管婴儿的话，选择河北省二院或者是河北省四院都是比较好的，不过要做三代试管的话，现目前还是选择石家庄省二院比较好。
