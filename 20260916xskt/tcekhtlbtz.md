# 爱让“星星的孩子”不再孤独

> 更新时间：2026-09-16 (UTC+8)

有这样一群孩子，他们活泼又可爱，他们不是聋子，却对世界的声音充耳不闻，他们不是哑巴，却从来不知道该如何开口说话，他们有着一对漂亮的大眼睛，却迷离漂移不定，时时躲避任何人的视线，他们被称作“星星的孩子”。他们美丽并且孤独，像天上的星星，漂亮、神秘，虽然跌落人间，却依然沉溺于自己的世界，和这个地球隔着百万光年。人们无从解释，只好把这样的孩子叫做“星星的孩子”——孤独症儿童。就“孤独症”的字面意思来看，那些儿童似乎只是不善交际，不愿与人沟通，但其实，孤独症是一种严重孤独，语言发育障碍，刻板重复动作和对环境奇特的反应为特征的精神疾病，它对家庭所造成的打击可以说是“毁灭”性的。近年来，孤独症患病率明显上升，其发病率约为每一百五十名儿童中就有一人，全球罹患孤独症的总人数已远超7000万，成为日趋严重的全球性健康危机。

 

　　从2008年起，联合国将每年的4月2日定为世界孤独症日，呼吁我们更加关注孤独症，关注孤独症儿童，提高对孤独症的认识，争取早期治疗积极干预，让这些“星星的孩子”走入人间，不再孤独。迄今为止，全世界的绝大多数国家都已加入到普及和提高孤独症意识的行列中来。2013年，全世界七大洲的101个国家，1300多个城市的8400多个地标和建筑物还共同参与了象征着为孤独症儿童点燃希望之灯火的“ 点亮蓝灯 ”（Light It Up Blue）的行动。孤独症家庭和社会各界的爱心人士更是身着蓝色盛装，在世界各地与之呼应，传递“世界孤独症日”和“点亮蓝灯”行动的图标、照片、文章和视频讯息。

 

　　2014年4月2日第七个世界孤独症日即将到来，中国精协孤独症委员会也特别为此发布了旨在倡导全社会给予孤独症症人士家庭更多理解与支持，强调构建融合社区环境和完善社会支持体系的主题暨宣传口号 ——“孤独症人士家庭支持及社区融合”。

 

　　亲爱的朋友，也许您今天才第一次听到，也许您曾在影视中看到过他们，也许他们就在您的身边。无论您与他们的距离是远是近，为了每个生命都有机会发出其璀璨的光芒，也为了我们的社会终能实现公正、平等、包容与爱。请让我们于4月2日当天， 以自己力所能及的方式为这群“ 星星的孩子 ”点亮希望的蓝灯，让美好的梦想早日成真。（儿童青少年心理门诊 吴歆 陈翠华）
